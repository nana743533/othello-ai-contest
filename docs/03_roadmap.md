# 「足りない基礎」の現在地

既にある自作教材 `knowledge/study/20260808_ai-engineer-fundamentals.md` の **§12 数学の最小セット** には、こう書いてある:

> 「論文を読む」ためではなく**「議論についていく」ための最小限**。……**手を動かして計算できる必要はない**。「勾配 = 損失が最も減る方向」が言えれば当面足りる。

**これは遂行力の基準としては正しい。** 案件でAIの話について行くにはこれで足りる。
**そして、これがそのまま「足りない基礎」の正体でもある。** 到達力の山では、ここを一段上げる — 「言える」から「**導出できる・実装できる**」へ。

| 分野 | 今の水準（§12） | このプロジェクトで要る水準 | 埋める場所 |
|---|---|---|---|
| **線形代数** | ベクトル・内積・行列積が言える | 評価関数 f(x)=**w·x** を内積として書き下せる／疎ベクトルで実装できる | Phase 2 |
| **微分** | 「勾配＝損失が最も減る方向」と言える | 二乗誤差の **∂L/∂w を紙で導出できる** | Phase 2 |
| **最適化** | （§12に項目が無い） | **SGDを自分で書いて収束させられる**／学習率の効きを説明できる | Phase 2 |
| **汎化** | 過学習・交差検証を知っている | train/val を切り、**正則化の効果をグラフで示せる** | Phase 2 |
| **確率・統計** | 平均・分散・正規分布が言える | **勝率の信頼区間を計算できる**／回帰の残差分散を推定できる | Phase 1・Phase 3（準1級と重なる） |
| **探索** | ゲームAI教材2章が**未読** | αβがなぜ速いかを説明でき、**自分のコードの各行の根拠を言える** | Phase 1 |

# Phase 2 — 評価関数を「学習」させる（10月下旬〜1月・本体・約50h）

**ここがこのプロジェクトの存在理由。** 強いオセロAI（Logistello、Egaroucid）は手書きの評価関数ではなく、**パターン特徴＋大量データからの学習**で評価関数を作っている。

> 11月は準1級の追い込み期。**オセロ側は【入】だけを進め、【実】は12/5の受験後に集中させる**（下の「時間とスケジュール」参照）。

## 【入】2-1 線形モデルと最小二乗法

- 教材: 『Pythonで始める機械学習』2章 線形モデル（**tasks.md に未読タスクとして既にある本**）
- 何を: 評価関数 f(x)=w·x が**内積そのもの**であること／二乗誤差を最小にする w／正規方程式
- **理解の確認**: 2変数の最小二乗を**紙で解ける**／numpy 10行で同じ答えが出せる

## 【入】2-2 勾配降下法とSGD

- 何を: 偏微分・勾配・更新式 w ← w − η∇L／バッチとSGDの違い／学習率の効き方
- **理解の確認**: 二乗誤差の **∂L/∂w を紙で導出できる**／SGDを自分で書いて損失が下がるグラフを描ける

## 【入】2-3 過学習・正則化・汎化

- 教材: 同書2章（Ridge / Lasso）
- 何を: train/val 分割／L2正則化が何をしているか（なぜ重みを小さくすると汎化するか）
- **理解の確認**: わざと過学習させ、**正則化で validation 誤差が下がるのをグラフで見せられる**

## 【入】2-4 先行実装を読む

- Michael Buro "Experiments with Multi-ProbCut and a New High-Quality Evaluation Function for Othello"（1997）— パターン評価関数の原典
- Egaroucid の eval 部分（`reserch/Egaroucid/` に fork 済み）
- **理解の確認**: 「なぜこのパターン集合なのか」を、**自分の対局感覚と突き合わせて**説明できる ← 競技オセロの優位性が出る場所

## 【実】2-5 パターン特徴（n-tuple）を設計する

定番: 辺＋X打ち、角の3x3、対角線、横列・縦列。**なぜそのパターンかを自分で言えること**を条件にする。

## 【実】2-6 学習データを用意する

自己対戦で局面を大量生成、または公開棋譜DB（WTHOR＝フランスオセロ連盟の大会棋譜）。ラベルは最終石差 or 深い探索の評価値。

## 【実】2-7 学習コードを書く

ステージ別（空きマス数で区切る）に線形モデルを持たせ、SGDで学習させる。

## 【測】2-8 学習済み評価関数 vs 手書き評価関数

自己対戦で**勝率＋信頼区間**を出す。**ここで勝ち越したら、この山の主目的は達成**。提出して順位も記録する。
